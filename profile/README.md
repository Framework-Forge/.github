# Pinel Box

Comunidade open source brasileira baseada em Qbox para FiveM.

## Sobre a Pinel Box

A Pinel Box é uma framework moderna, modular e open source para servidores
RolePlay, mantendo compatibilidade com o ecossistema Qbox e a stack Ox.

O projeto prioriza:

- Performance
- Segurança
- Código limpo
- Organização modular
- Compatibilidade
- Facilidade de deploy
- Ferramentas para desenvolvedores

## Tecnologias

- Qbox
- Ox Library
- Ox Inventory
- Ox Target
- PMA Voice
- Ox MySQL
